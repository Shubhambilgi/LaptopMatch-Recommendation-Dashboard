# LaptopMatch – Recommendation Dashboard

A Power BI data analytics project focused on **laptop comparison and recommendation** using a structured laptop dataset.

## Overview

LaptopMatch is a data analytics project designed to make laptop comparison easier by organizing laptop specifications and pricing information into a format that can be explored and analyzed through **Microsoft Power BI**.

The project uses a structured laptop dataset to analyze different laptop characteristics and support data-driven comparison between available laptop models.

The Power BI dashboard is currently being developed and will be refined to provide an interactive and user-friendly way to explore the dataset.

## Project Objective

The main objectives of this project are to:

- Analyze laptop specifications and pricing
- Compare laptops based on their specifications
- Explore patterns and relationships within the dataset
- Build interactive data visualizations using Power BI
- Make laptop comparison easier through data-driven analysis
- Develop a recommendation-oriented dashboard

## Dataset

The project uses a structured laptop dataset containing information about laptop models, specifications, and pricing.

The dataset is stored in:

Data/laptop_dataset_large.csv

This dataset serves as the primary source for data preparation, analysis, and visualization.

## Power BI Dashboard

The project uses **Microsoft Power BI** to transform the laptop dataset into an interactive analytical dashboard.

The dashboard is intended to help users explore and compare laptops using different specifications and pricing-related information.

The Power BI project file is stored in:

PowerBI/LaptopMatch.pbix

> **Note:** The dashboard is currently under development. Dashboard screenshots, detailed features, and final insights will be added after the dashboard is completed.
